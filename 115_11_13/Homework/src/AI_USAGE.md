## 我的反思

哪一句需求幫我判斷AI建議：Mission.java 的註解「指令 0 也先記錄，再把 returned 設為 true 並離開迴圈」，讓我確認 history.add 必須放在 if (command == 0) 之前，並用腳本 {0,1} 驗證（步數=1、略過=1）。另外「無效指令不計入指令次數但仍留在日誌」讓我用 {1,9,-1} 檢查拒絕=2。
只看類別圖還不能證明什麼：類別圖只顯示類別之間的欄位、方法與關係，不能證明程式執行起來是對的。像 run 要先檢查 isStopped、指令 0 要先記錄、空日誌要回傳 -1，這些邏輯都要實際編譯並用不同腳本（{1,1,2}、{0,1}、{1,9,-1}、{}）執行，才能確認。
